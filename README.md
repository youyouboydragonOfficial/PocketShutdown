# Pocket Lock (v2.4.0)

イヤホンのダブルタップ（音量UP/DOWN）や1回タップ（再生/停止）、またはスマホ本体の音量キーを**3秒以内に連続で2回**押すと、画面をOFFにして端末をロックするAndroidツールです。

## 主な機能・特徴 (v2.4.0)

- **🎧 イヤホンのダブルタップ（音量操作）に完全対応！**:
  - 「イヤホンダブルタップ＝音量UP/DOWN」のイヤホン仕様に合わせ、音量キーの判定ウィンドウを従来の650msから**3秒以内（3000ms）**に大幅拡大！
  - イヤホンのダブルタップを3秒以内にポンポン…ポンポンと2回行うだけで、100%確実に画面OFF＆ロックされます。
- **📱 スマホ本体の音量ボタンでも動作**:
  - イヤホンを接続していない時でも、スマホ本体の音量キー（UPまたはDOWN）を3秒以内に2回ポチ・ポチと押すだけで画面を即座に消灯・ロックできます。
- **🎵 メディアキー（1回タップ＝再生/停止）も同様に対応**:
  - イヤホンの1回タップ（再生/停止操作）を3秒以内に2回連続で行うことでも画面OFF可能。
- **⚠ 危険区域 (DANGER ZONE) 搭載**:
  - 使わない時は「🛑 全設定をOFFにして完全停止」ボタンで全機能とバックグラウンド監視をワンタップで完全休止できます。
  - 再び使いたい時は「🔄 推奨設定に一括復元」でいつでも元通りに再開可能。
- **端末の音楽イコライザー（三本バー）誤作動ゼロ**:
  - バックグラウンド無音オーディオを廃止し、端末が勝手に「音楽再生中」と誤認してボリュームバーが動く問題を完全に解消。
- **滑らかなリアルタイム進行バー & DLアニメーション**:
  - 60fpsで滑らかに伸びるグリーン進行バーと光沢シマー演出、光る浮遊矢印＆光のデータストリームが降り注ぐUnity風ダウンロードアニメーションを搭載。

## 使い方

1. アプリを起動し、「ユーザー補助を設定」をタップして Pocket Lock をONにする
2. イヤホンのダブルタップ（音量UP/DOWN）または1回タップ（再生/停止）を**3秒以内に連続で2回**行う
   （※スマホ本体の音量ボタンを3秒以内に2回押しても動作します）
3. 画面がOFFになり、端末がロックされます（短く振動します）
