# Pocket Lock (v1.6.0)

イヤホン（Bluetooth／有線）の操作ボタンや音量ボタンを素早く2回押すと、アクセシビリティ（ユーザー補助）のグローバルアクションで画面をOFFにして端末をロックするAndroidツールです。

## 主な機能・改善点 (v1.6.0)

- **幅広いイヤホンボタン対応**:
  - イヤホンの操作ボタン（中央ボタン／Hook）、再生・一時停止ボタンのダブルタップ
  - イヤホンの音量ボタン（UP / DOWN）のダブルタップ（同じ側を2回押し）
  - AirPodsや一部ワイヤレスイヤホンで採用されている「ダブルタップ＝曲送り (NEXT)」のワンアクション対応
- **判定時間の改善**:
  - Bluetoothイヤホンの通信遅延を考慮し、ダブルタップ受付時間を650msに最適化。
- **有線・Type-Cイヤホン対応**:
  - Bluetooth接続だけでなく、有線イヤホンやType-C接続時でも動作。
- **触覚フィードバック（バイブレーション）**:
  - ロック成功時に本体が短く振動するため、ポケットに入れたままでも画面OFFが確認可能。
- **入力診断＆状態モニター**:
  - アプリ画面上で、押されたキー名・キーコード・経過時間・イヤホン接続状態をリアルタイム表示。

## 使い方

1. アプリを起動し、「ユーザー補助を設定」をタップして Pocket Lock をONにする
2. イヤホンを接続した状態で、イヤホンのボタンまたは音量ボタンを素早く2回押す
3. 画面がOFFになり、端末がロックされます（短く振動します）
