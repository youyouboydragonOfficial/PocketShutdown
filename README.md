# Pocket Lock (v1.8.0)

イヤホンボタンを2回連続押して音楽を再生・停止する機能を利用し、その操作（ダブルタップ）を**3秒以内に連続**で行うと画面をOFFにして端末をロックするAndroidツールです。

## 主な機能・特徴 (v1.8.0)

- **Unity風スタジオロゴ・スプラッシュ画面**:
  - アプリ起動時に「YOUYOUBOYDRAGON STUDIO」のエンブレムロゴが優雅にフェードイン・フェードアウト（約2.4秒でスムーズにメイン画面へ遷移。タップで即スキップ可能）。

1. **イヤホン操作を活かした自然なロック**:
   - イヤホンのダブルタップ（再生/一時停止）を1回行うと、通常通り音楽が再生/停止します。
   - **3秒以内にもう一度ダブルタップ**（合計2回の再生/停止操作）を行うと、画面がOFFになり端末がロックされます。
   - 普段音楽を操作したいだけの場合は、1回ダブルタップした後に放置すれば画面は消えません。
2. **音量ボタン操作**:
   - イヤホンの音量ボタン（UP/DOWN）を同じ側で素早く2回押しても画面をロック可能。
3. **有線・Type-C・Bluetooth全対応**:
   - Bluetoothイヤホンだけでなく、有線イヤホンやType-Cイヤホンでも動作します。
4. **触覚フィードバック（バイブレーション）**:
   - 画面OFF時に端末が短く「ブルッ」と振動するため、ポケットに入れたままでも確実に分かります。
5. **入力診断UI**:
   - 画面上で受信したキーコード、イヤホン接続状態、残り時間をリアルタイムに確認可能。

## 使い方

1. アプリを起動し、「ユーザー補助を設定」をタップして Pocket Lock をONにする
2. イヤホンのボタンで再生/一時停止操作（ダブルタップ）を**3秒以内に連続で2回**行う
3. 画面がOFFになり、端末がロックされます（短く振動します）
